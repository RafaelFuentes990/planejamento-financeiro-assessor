# Private Banking · Planejamento Financeiro

Aplicação web de página única (SPA) 100% autocontida para mapeamento e planejamento financeiro de clientes pessoa física.

## Como usar

1. Abra o arquivo `index.html` no navegador, **ou**
2. Após habilitar GitHub Pages (Settings → Pages → Source: Deploy from a branch → main / root), acesse:
   `https://rafaelfuentes990.github.io/planejamento-financeiro-assessor/`

## Recursos

- Multi-cliente com persistência em localStorage
- Wizard de 7 etapas
- Dashboard com Chart.js
- Relatório executivo gerado por regras
- Tema claro/escuro
- Design Private Banking (dourado + carvão)

> Os dados ficam apenas no navegador do usuário. Não há backend nem sincronização entre dispositivos.
